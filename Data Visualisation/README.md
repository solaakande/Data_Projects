Traffic Accidents in the Netherlands: Data Analysis using SAS

## Overview
This project analyses traffic accident data from the Netherlands using SAS Visual Analytics.  

The aim is to identify patterns in accident occurrence, understand contributing factors, and provide recommendations to improve road safety and support insurance claim evaluation.

## Project Structure

### Task 1: Location Analysis (Where)
- Analysed accident distribution across provinces  
- Compared urban and non-urban accident patterns  
- Identified high-risk regions with the highest accident counts  
- Found that Zuid-Holland and Noord-Holland have the highest accident rates  

### Task 2: Time Analysis (When)
- Examined accident trends by month, day, and hour  
- Identified peak accident periods  
- Discovered that accidents are most frequent on Thursdays and Fridays  
- Found that peak accidents occur between 5–6 PM (rush hour)  

### Task 3: Offender Analysis
- Analysed vehicle types involved in accidents  
- Compared insured and uninsured drivers  
- Found that passenger cars are involved in the majority of accidents  
- Identified that 33.5% of accidents involve uninsured drivers  

### Task 4: Casualty Analysis
- Analysed age groups affected by accidents  
- Examined injury severity levels  
- Found that the 31–60 age group is most affected  
- Observed that a large proportion of casualties require hospital treatment  

### Task 5: Accident Type Analysis
- Analysed accidents by road type and weather conditions  
- Identified common accident types (e.g. side collisions)  
- Found that most accidents occur on straight roads  
- Observed that most accidents happen under dry weather conditions
