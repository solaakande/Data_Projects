# 📊 Income Disparities Analysis

## 🧠 Overview
This project analyses income inequality using 2021 UK household census data, focusing on how factors like education, gender, and age influence earnings.

---

## 🎯 Key Insights
- 📈 Higher education levels strongly correlate with higher income  
- 👩‍💼 Women in this dataset earn more than men across all education levels (unusual finding)  
- 📉 Significant income variation exists across demographic groups  

---

## 🛠️ Tools
- R / Quarto  
- Data visualisation (ggplot2)  

---

## 📊 Project Workflow
- Data Cleaning  
- Exploratory Data Analysis  
- Visualisation & Insight Generation  

---

## ⚠️ Limitations
- Missing values in income and demographics  
- Presence of extreme outliers  
- No job role data (limits interpretation)
