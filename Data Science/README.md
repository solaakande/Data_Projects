# Income Disparities Analysis

## Overview
This project explores income inequality using UK household census data (2021).  
I analysed how factors like education, gender, and age relate to income and tried to identify patterns across different groups.

## Key Findings
- Higher education levels are generally associated with higher income  
- In this dataset, women earn more than men across all education levels, which is an unusual result  
- Income varies significantly across age groups and education levels  

## Tools
- R  
- Quarto  
- ggplot2  

## What I Did
- Cleaned and prepared the dataset  
- Explored relationships between income and demographic variables  
- Created visualisations to highlight trends  

## Limitations
- Some missing data in key variables  
- Presence of extreme income values  
- No job role information, which limits deeper interpretation
