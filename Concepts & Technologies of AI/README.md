# Machine Learning Applications: Regression, Clustering and Classification

## Overview
This project applies different machine learning techniques to real-world datasets to explore patterns, make predictions, and compare model performance.

It covers regression, clustering, and classification tasks, along with a brief discussion of ethical considerations in AI.

## Project Structure

### Task 1: House Price Prediction (Linear Regression)
- Built models to predict house prices using features like living area and quality  
- Compared a single-feature model with a multi-feature model  
- Evaluated performance using R² and error metrics  
- Found that additional features slightly improved accuracy  

### Task 2: Country Clustering (K-Means)
- Grouped countries based on socio-economic and health indicators  
- Used features such as income, child mortality, life expectancy, and GDP  
- Created 2D and 3D visualisations to show cluster patterns  
- Identified clusters representing different levels of development  

### Task 3: NBA Rookie Career Prediction (Classification)
- Predicted whether a player’s career would last more than 5 years  
- Tested and compared three models:
  - Logistic Regression  
  - Gaussian Naive Bayes  
  - Neural Network  

**Approach**
- Selected relevant features based on correlation  
- Scaled features before training  
- Used train/test split for evaluation  
- Compared models based on accuracy and misclassification  

**Key Result**
- Neural network performed slightly better than the other models, capturing more complex relationships  

### Task 4: AI Ethics
- Explored ethical challenges in AI systems  
- Discussed decision-making in autonomous vehicles  
- Considered issues such as bias, fairness, and responsibility
